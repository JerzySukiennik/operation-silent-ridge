# World asset pipeline (world module)

Everything under `assets/world/` is generated by these seeded scripts (Mac, Python 3 + numpy,
scipy, Pillow; a C compiler; Blender 4.5 for the tree). Run from the repo root, in this order:

| step | command | output | time (M-series/Intel Mac, 16 threads) |
|---|---|---|---|
| 1 textures | `python3 game/tools/terrain/fetch_textures.py` | Poly Haven CC0 downloads in `assets/world/src/polyhaven/`, packed `assets/world/textures/*_albedo_h.png` (RGB + height in A), `*_normal.png`, `noise.png` | 1–2 min |
| 2 water | `python3 game/tools/terrain/make_water.py` | `water_normal_a/b.png` (Phillips-spectrum FFT, tileable) | seconds |
| 3 tree card | `python3 game/tools/terrain/make_branch.py` | `assets/world/src/tree/branch_*.png` from the fir twig atlas | seconds |
| 4 tree | `/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P game/tools/terrain/make_tree_blender.py -- "$PWD/game"` | `assets/world/trees/fir.glb` (≈700 tris) + impostor renders | ~10 s |
| 5 atlases | `python3 game/tools/terrain/make_impostor_atlas.py` | `assets/world/trees/fir_billboard_*.png`, `fir_twig_*.png`, `fir_bark_albedo.png` | seconds |
| 6 terrain | `python3 game/tools/terrain/gen_terrain.py [--seed 1729]` | `assets/world/src/height.r16` → `assets/world/terrain/height.res` (packed by Godot headless in a scratch project), `masks_a/b.png`, `scripts/world/world_layout.gd` | 15–25 min |
| 6b masks only | `python3 game/tools/terrain/gen_terrain.py --masks-only` | re-bakes AO / sun / flow / forest / water masks from the existing height | ~1–10 min |
| 7 imports | `python3 game/tools/terrain/write_imports.py` | `.import` presets for new textures (VRAM-compressed, BC5 normals, lossless masks) | – |

Look-dev without touching the project: `gen_terrain.py --size 2048 --preview-only --work <dir>`
writes hillshade previews (`prev_*.png`) into `<dir>`.

Terrain generation stages (all in `gen_terrain.py`, heavy loops in `kernels.c`):
A) 1024² stream-power fluvial erosion with tectonic uplift (Braun & Willett implicit solver),
canyon floor and target valley held as fixed base level so the range drains into them;
B) 2048² refinement + glacial U-valley widening, fjord subsidence along the coast, canyon gorge
carve (buttresses, soft ledges, fall-line couloirs); D) 4096² detail + droplet hydraulic erosion
+ thermal talus; E) 8192² fine detail + droplets + thermal; coastal cliffs; flight-corridor
enforcement. Masks are baked at 4096²: horizon AO (16 dirs), soft sun visibility for the fixed
sun, MFD flow, sediment, curvature, forest density, rivers.
